# slipway-core

Общие типы и макросы [Slipway](https://github.com/anishukserg/slipway): ссылки на документы, непустые строки и списки, обратимость изменений, таксономия.

Крейт не содержит ни схемы документов, ни схемы работы — только то, что нужно обоим слоям. Зависимостей нет: его подключают и атрибут разметки, и скан, работающий в `build.rs`.

- **Ссылки на документы** — `AdrRef`, `RfcRef`, `SliceRef`, `WorkRef` и другие — не собираются конструктором: константы порождает скан реестра, поэтому ссылка на несуществующий документ не компилируется.
- **`NonEmpty` и `NonEmptyStr`** — пустой список и пустая строка там, где они ничего не значат, невыразимы.
- **`BlastRadius`** — радиус изменения по обратимости; от него зависит требуемая независимость проверяющего.
- **`declare_taxonomy!` и `taxon!`** — значения осей таксономии продукта; опечатка в значении — ошибка компиляции.
- **`date!`** — дата в const-контексте; несуществующая дата не компилируется.

Методология, гарантии и остальные крейты — в [репозитории](https://github.com/anishukserg/slipway#readme).
