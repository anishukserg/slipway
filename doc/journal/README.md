# Журнал работы Slipway

Каталог событий слоя работы (решение 15, `doc/adr/a0015.rs`). Состояние каждой единицы работы и среза — свёртка этих файлов при сборке крейта документов; статусных полей нет.

- Одно событие — один файл `<работа или срез>/<ГГГГММДДTЧЧММССZ>-<событие>.toml`.
- Файл не изменяется и не удаляется после коммита.
- Формат — плоское подмножество TOML: строки `ключ = "строка"` и комментарии.
- События пишет инструмент (работа w0023), а не человек руками.

| Событие | Предмет | Поля сверх `event`, предмета и `at` |
|---|---|---|
| `started` | работа | — |
| `gate` | работа | `gate`, `tree`, `verdict` |
| `landed` | работа | `commit`, `tree`, необязательное `evidence = "history"` |
| `abandoned` | работа | `reason` |
| `closed` | срез | — |

Автомат работы: без событий → `started` → `landed` или `abandoned`. `gate` — только у начатой работы; `landed` требует `gate` с тем же деревом; `landed` с `evidence = "history"` — только у работы без событий. Нарушение не собирается, и ошибка называет файл события.
